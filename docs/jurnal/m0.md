## Bukti "selesai"

Setiap jenis bukti dicatat terpisah, karena masing-masing membuktikan hal berbeda:

| Bukti | Yang dibuktikan |
|---|---|
| CI hijau di `main` | Kode lulus format, lint, tes, dan build tanpa `std` di mesin bersih |
| Halaman Pages di HP | Rantai lengkap: Rust → wasm → deploy → browser HP asli |
| Label `build 71e8aca` di HP | Cache busting bekerja; HP menampilkan versi terbaru |
| `cargo test` di laptop pemilik | Panduan setup bisa diikuti orang lain, bukan hanya di mesin pembuatnya |
| `build-web.ps1` + server lokal dibuka dari HP | Jalur pengembangan lokal di Windows bekerja |

## Pelajaran

1. **PR bertumpuk tidak otomatis pindah base.** #2–#4 masuk ke branch base
   masing-masing, bukan ke `main`, sehingga perlu PR #5 untuk menyatukan.
   Pencegahan: aktifkan *Automatically delete head branches*, atau ubah base
   ke `main` sebelum merge.
2. **"Sudah deploy" ≠ "sudah terlihat".** HP menyimpan CSS lama selama 10 menit.
   Masalah yang terlihat di HP asli melahirkan ADR-0009. Emulasi di laptop tidak
   akan menemukannya.
3. **Bukti harus bisa dilihat oleh orang yang memeriksa.** `view-source:` tidak
   tersedia di browser HP, jadi versi build ditampilkan di halaman.
4. **Panduan diuji oleh pembaca, bukan penulisnya.** Error `could not find
   Cargo.toml` (salah folder) masuk ke tabel "Masalah umum".
5. **ADR yang sudah diterima tidak diedit diam-diam.** Perubahan lokasi output
   build dicatat di ADR-0009, yang merujuk ADR-0003.

## Angka

- `gb_web_bg.wasm`: ±19 KB
- CI di PR: ±30 detik (`check`), ±20 detik (`web`, dengan cache);
  run pertama tanpa cache ±2 menit
- Tes: 3 unit test
